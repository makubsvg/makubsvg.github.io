TriangleRTS is my ambitious work in progress real time strategy game.
It supports a wide range of complex rts and other features already such as:
- carefully fine-tuned formation, pathfinding, avoidance, reaction, proaction and movement unit systems,
- a data driven design for game objects like units, turrets etc,
- a unique art style committed to mostly using triangles,
- working but not yet fully featured editors for maps and triangle shapes,
- a custom engine written in C++ using SDL2 and OpenGL ([PlanetEngine]({% link _projects/planet-engine.md %})).
One key goal of this project is to create a powerful rts engine that handles various kinds of rts game systems.
Indeed, additionally to the game and engine I want it to have powerful but easy to use editors for various aspects of the game.
