Triangle RTS is my ambitious work in progress real time strategy game.
It features a wide range of complex rts and other features already such as:
- carefully finetuned formation, pathfinding, avoidance, reaction, proaction and movement unit systems,
- a data driven design for game objects like units, turrets etc,
- a unique artstyle committed to mostly using triangles,
- working but not yet fully featured editors for maps and triangle shapes,
- a custom engine written in C++ using SDL2 and OpenGL (PlanetEngine).
One key goal of this project is to create a powerful rts engine that supports various kinds of rts game systems.
Indeed, additionally to the game and engine I want it to have powerful but easy to use editors for various aspects of the game.
